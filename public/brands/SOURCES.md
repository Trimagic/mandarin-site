# Brand SVG sources

Asus, Lenovo, HP, Acer, Dell, MSI, LG and Sony: Simple Icons 11.15.0,
downloaded from https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/icons/.
Simple Icons artwork is distributed under CC0; trademarks belong to their owners.
Wordmark viewBoxes are tightened for legibility at small display sizes.

Philips: local typographic SVG label (Arial/Helvetica bold), not an official vector logo.

Existing Apple, Samsung, Xiaomi, Huawei and Honor files are retained unchanged.
Computer category icons use the project's @tabler/icons-react SVG components.
